# SEO & Metadata Optimization Skill

Use this skill when optimizing pages for search engine visibility, social sharing previews, and performance indexing.

## SEO Checklist

1. **Title & Description Tags**
   - Single distinct `<h1>` per page with semantic hierarchy (`<h2>`, `<h3>`).
   - Title: Brand Name - Compelling Keyword Rich Title (< 60 chars).
   - Meta Description: Clear summary with strong call-to-action (< 160 chars).

2. **OpenGraph & Twitter Cards**
   - Provide `og:title`, `og:description`, `og:image`, `twitter:card: "summary_large_image"`.

3. **Semantic HTML**
   - Use `<main>`, `<nav>`, `<header>`, `<article>`, `<section>`, and `<footer>` elements.
