# AI Agent Prompt Engineering Skill

Use this skill when designing prompt templates, system instructions, and tool calling schemas for LLMs and autonomous agents.

## Prompting Frameworks

1. **Role & Constraint Anchoring**
   - Explicitly define the persona, target tech stack, and negative constraints (e.g. "Never output markdown fences when in JSON mode").

2. **Chain of Thought & Thinking Transparency**
   - Instruct the model to reason step-by-step through architecture, dependencies, and layout rhythm before generating code.

3. **Output Formatting Precision**
   - For structured JSON endpoints, provide strict TypeScript interface schemas in the system prompt.
