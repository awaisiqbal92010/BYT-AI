# Interactive Data Visualization Skill

Use this skill when building analytics dashboards, metrics cards, sparklines, and visual charts.

## Guidelines

1. **Stat KPI Cards**
   - Format metric cards with clear bold numbers, percent change badges (`+14.2%`), sparkline trend indicators, and Lucide icons.

2. **Accessible SVG Charts**
   - Use clean, scalable SVGs with gradients, stroke dashes, and tooltips on hover.
   - Support dark mode color adaptations automatically.
