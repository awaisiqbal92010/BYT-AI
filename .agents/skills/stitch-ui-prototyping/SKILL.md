# Stitch UI Prototyping Skill

Use this skill when leveraging Stitch MCP to design user interfaces and generate design tokens before writing React components.

## Stitch MCP Design Flow

1. **Design Token Generation**
   - Extract semantic primary, secondary, and accent colors from user concept.
   - Establish cohesive typography scale and card corner radiuses.

2. **Bento-Grid Wireframing**
   - Outline key sections (Header, Hero Showcase, Interactive Workspace, Feature Matrix, Pricing / Footer).
   - Define exact visual style directives for each component before code synthesis.

3. **Stitch-to-React Conversion**
   - Transform Stitch section blueprints into modular JSX components located in `src/components/`.
   - Incorporate Lucide icons on all action items and navigation links.
