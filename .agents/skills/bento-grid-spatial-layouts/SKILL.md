# Bento Grid & Spatial UI Layouts

## Design System Rules
- **Hierarchy Mapping**: Main KPI card takes `col-span-2 row-span-2`; secondary stats take `col-span-1`.
- **Consistent Radius & Gaps**: Standardize on `gap-4 md:gap-6` and `rounded-2xl border border-border/70`.
- **Internal Padding**: Minimum `p-5 md:p-6` within bento cards to let content breathe.
- **Adaptive Breakpoints**: Collapse to single-column flex flow below 768px for seamless mobile ergonomics.
