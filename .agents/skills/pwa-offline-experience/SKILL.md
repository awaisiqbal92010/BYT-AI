# PWA & Offline Experience Skill

Use this skill when implementing Progressive Web App manifests, service worker caching, and offline state handling.

## PWA Rules

1. **Web App Manifest**
   - Provide `manifest.json` with `name`, `short_name`, `theme_color`, `background_color`, `display: "standalone"`, and responsive icon sizes.

2. **Graceful Offline Indicators**
   - Detect `navigator.onLine` and display an unobtrusive offline banner or cached workspace view when connectivity drops.
